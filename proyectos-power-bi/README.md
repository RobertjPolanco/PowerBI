# Proyectos de Power BI

Espacio para tableros y proyectos aplicados de Power BI. Crear una carpeta por proyecto, con un nombre claro.

Cada proyecto debe incluir un README con su objetivo, fuentes de datos, instrucciones de actualización y descripción de sus archivos.

Esta carpeta todavía no contiene tableros. Los apuntes del curso están en [Formación en Power BI](../formacion/power-bi/).
